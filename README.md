### ⭐ ระบบหลัก

#### 🧑‍🎤 ตัวละคร & คลาส

**สร้างได้หลายตัว** — เลือกชื่อ + 1 ใน 4 คลาส สลับเล่นได้ เปลี่ยนชื่อได้ ลบได้ (ยืนยัน 2 ครั้ง)

🎭 **จุดเด่น/จุดด้อยเฉพาะคลาสตามช่วงเวลา** (☀️ 06:00–17:59 / 🌙 18:00–05:59 ตามเวลาจริง):

| คลาส | ☀️ กลางวัน | 🌙 กลางคืน |
|---|---|---|
| ⚔️ นักรบ | มอนสเตอร์อ่อน 15% + เจอบ่อยขึ้น + ตีบอส +10% | มอนสเตอร์แข็ง 15% + ตีบอส -10% |
| 🔮 นักเวทย์ | XP -10% + ตีบอส -10% | XP +25% + ตีบอส +10% + ใช้สกิลถี่ 2.5x |
| 🗡️ โจร | — | ทอง +30% + เจอสมบัติ x1.25 + ตีบอส +10% แต่กับดัก x1.3 |
| ✨ นักบวช | ศาลเจ้า x1.25 + รางวัล +25% + ตีบอส +10% | มอนสเตอร์แข็ง 10% |

### ⏸️ ระบบพัก

ระบบพักออกแบบตาม Pomodoro — แบ่งเป็น 3 ประเภท:

**⏸️ พักกลาง session** — กดหยุดพัก/กลับหน้าหลัก = timer หยุด ไม่สะสม XP/เลเวล
- **⏸️ พักสั้น** — เหมาะเข้าห้องน้ำ/รับสาย (นับเวลาแยกจากพักระหว่าง session)
- **😴 พักยาว** — เหมาะนอน/ธุระยาว (แยกหมวดสถิติ "พักยาว" ออกจากพักสั้น)
- กลับมาแล้วกด **▶️ โฟกัสต่อ** จากแถบ sticky ด้านบนหน้า Home

**⚠️ auto-discard พักเกินเวลา** — Pomodoro-based:
| ประเภทพัก | เตือนเมื่อ | ทิ้งอัตโนมัติ |
|---|---|---|
| ⏸️ พักสั้น | >10 นาที | +5 นาที → ทิ้ง session |
| 😴 พักยาว | >60 นาที | +5 นาที → ทิ้ง session |

- วงแหวนเปลี่ยนสี 🟡 เตือน → 🔴 เกินเกณฑ์ + browser notification
- กด "ยังพักต่อ" ได้ — เตือนใหม่ครั้งถัดไปที่ 2 เท่า
- **XP/ทองจาก event ระหว่าง session ยังได้ตามปกติ** (บันทึกทันทีตอนเกิด event) — สิ่งที่หายไปคือ **โบนัสจบ session** (`100+20×level` XP + `25+8×level` ทอง) + คอมโบ

**💨 ทิ้ง session** — ถามเหตุผลก่อน (บังคับเลือกจากตัวเลือกสำเร็จรูป) · บันทึกเหตุผล + เวลาที่โฟกัสลง log · ดูย้อนหลังได้

### 📈 เลเวล & แต้มสถานะ

- สะสม XP → เลเวลอัพ → ได้แต้มจัดสรรเอง (HP / MP / ATK / DEF / SPD) พร้อมการเติบโตอัตโนมัติ
- ปุ่ม **"จัดอัตโนมัติ"** แจกแต้มตามน้ำหนักคลาส + ปรับตามอุปกรณ์ที่สวม (เกียร์ให้ stat ไหน → น้ำหนักลด ไปเติม stat ที่ขาด)
- 🔍 **โหมดวางแผน** — ดูผลลัพธ์ก่อนยืนยัน (dry-run) โชว์ stat ก่อน/หลัง + ของที่จะสวมได้ใหม่

### 🎒 ไอเทม & อุปกรณ์

**ช่องสวมใส่ 11 ช่อง**: อาวุธมือหลัก/มือรอง, หมวก, เกราะ, แขน, ขา, เท้า, เครื่องประดับ x4

- อุปกรณ์มี **ข้อจำกัดการสวม**: บางชิ้นเฉพาะคลาส (ป้าย 🎭 สีประจำคลาส), ต้องเลเวลขั้นต่ำ, หรือค่าสถานะถึงเกณฑ์
- 🐾 **ล่าได้ของ** — ชนะมอนสเตอร์ ~40% ได้ของ · ชนะบอส ~50% ได้ของรางวัล
- 🔍 **เทียบอุปกรณ์** — กดปุ่ม "🔍 เทียบกับที่สวม" เห็น stat ทีละตัว เทียบของใหม่ → เก่า พร้อมผลต่าง ▲/▼
- 🎒 **กระเป๋า 20 ช่อง** — เต็ม + รับของรางวัล → ขายอัตโนมัติ · เต็ม + ซื้อ/คราฟต์ → บล็อก

| 📋 แบบแปลน | 25% | เรียนสูตรครบ 4 สูตร → เลิกขาย (ของซ้ำสำหรับยกระดับได้จากดรอป/บอสเร่ร่อน) |
| 💎 ของหายาก | ราคาเต็ม | ไม่ลดซ้ำ (ตลาดมืดรับซื้อ +25% อยู่แล้ว) |

| ✨ ของพิเศษ exclusive | 10% | ยกเว้นถุงเงินนำโชค |
| 📦 กล่องลึกลับ | ราคาเต็ม 180 | สุ่มของคุ้ม/เจ๊ง (คัมภีร์ 5% / หายาก 20% / เกียร์ 25% / ยา 50%) |

### 👹 ระบบต่อสู้บอส

สู้บอสแบบเทิร์น-by-เทิร์น (ช่วงพักยาว — ไม่รบกวนสมาธิ) — ต้อง **เลือกกลยุทธ์** ไม่ใช่แค่กดโจมตีซ้ำ:

| กลไก | รายละเอียด |
|---|---|
| 🛡️ **ตั้งรับ** | ลดดาเมจ 60% + ฟื้น MP 10% |
| 😡 **โกรธจัด (เฟส 2)** | HP ≤ 50% → ATK x1.4 + ท่าเด็ดถี่ขึ้น + ท่าไม้ตาย 💥 (x2.2) + ต้านแช่แข็ง |
| ⚠️ **ชาร์จท่าไม้ตาย** | ทุก 5 เทิร์น — ทำดาเมจ ≥ 12% HP บอส → สลายได้! |
| 🔥 **สุดทน** | >30 เทิร์น → ATK บอส x1.6 ถาวร |
| 🗺️ **สเกลตามเมือง** | x1.05/เมือง — เมือง 12 โหดกว่า ~x1.55 |
| ✨ **รางวัลฝีมือ** | สลายท่าไม้ตาย = +8% XP/ทอง (สูงสุด +24%) · ชนะตอนสุดทน = +15% ทอง |
| 🐉 **บอสเร่ร่อน** | สุ่มมาแทนบอสปกติบางสัปดาห์ — ชนะได้ของรางวัลการันตี + แบบแปลนคราฟต์ |
| 🏆 **ห้องเก็บถ้วยรางวัล** | ชนะบอสแต่ละตัวครั้งแรก → เก็บถ้วยในค่ายพัก |

## 🚀 วิธีรัน

**รันง่ายด้วย script** (ดูวิธีใช้เต็ม: `./run.sh help`):

```bash
./run.sh            # โหมดพัฒนา (server :3001 + frontend :5173)
./run.sh prod       # build + รัน production ที่ http://localhost:3001
./run.sh start      # รัน production แบบ background (log: /tmp/pomoquest.log)
./run.sh stop       # หยุด server
./run.sh reset      # RESET เกม: หยุด server → ลบ DB → รันใหม่ (พิมพ์ reset ยืนยัน, -y ข้าม)
./run.sh backup     # สำรอง DB ไปที่ backups/ (server รันอยู่ได้)
./run.sh backup --json   # สำรองเป็น .json.gz (บีบอัด, อ่าน/แก้ได้)
./run.sh restore    # กู้คืนจาก backup (.db หรือ .json.gz) — เช็คเวอร์ชัน schema ก่อน
./run.sh status     # ดูสถานะ server + LLM
./run.sh llm        # เช็คว่า LLM ที่ localhost:8080 พร้อมใช้ไหม
```

หรือรันด้วย npm:

```bash
npm install          # ติดตั้ง dependencies (ครั้งแรก)
npm run dev          # โหมดพัฒนา — server :3001 + frontend :5173
npm run build        # build frontend ไปที่ dist/
npm start            # รัน production — เสิร์ฟที่ http://localhost:3001
```

> 💡 บนมือถือ: เปิดเว็บใน Chrome → เมนู → **Add to Home Screen** → ใช้งานเหมือนแอพจริง

## ➕ เพิ่มเนื้อหาเกมเอง

ข้อมูลเกมทั้งหมดอยู่ในไฟล์เดียว: **`server/data.js`** — เกม engine อ่านจาก array เหล่านี้โดยตรง ดังนั้น **เพิ่มเนื้อหาใหม่ไม่ต้องแตโค้ดอื่นเลย** เปิดแอพใหม่แล้วใช้งานได้ทันที

### 🐾 เพิ่มมอนสเตอร์

เพิ่ม entry ใน `MONSTERS` array:

```js
{ name: 'กอร์กอน', icon: '🐍', power: 1.4, xp: 48, gold: 30, loot: 120 },
```

| field | ความหมาย |
|---|---|
| `name` / `icon` | ชื่อและอีโมจิ |
| `power` | ตัวคูณพลัง (0.7 = อ่อน, 1.5 = แรง) |
| `xp` / `gold` | รางวัลพื้นฐาน |
| `loot` | id ของไอเทมดรอป (~40% เมื่อชนะ) |
| `rare: true` | มอนสเตอร์พิเศษ 🌟 (เจอ ~1%) — ชนะการันตีดรอป loot |

**มอนสเตอร์ประจำเมือง** เพิ่มที่ `CITY_MONSTERS` (index ตรงกับ `CITIES`):

```js
{ name: 'กวางเขาทอง', icon: '🦌', power: 1.7, xp: 70, gold: 40, loot: 146, flavor: '…{monster}…' },
```

### ⚔️ เพิ่มอุปกรณ์ / ไอเทม

เพิ่ม entry ใน `ITEMS` array:

```js
// อาวุธ (handed: 1 = มือเดียว, 2 = สองมือ)
{ id: 14, name: 'ดาบเพลิง', icon: '🔥', type: 'weapon', atk_bonus: 12, price: 260, lvl: 4, handed: 1 },

// เกราะ/หมวก/แขน/ขา/เท้า
{ id: 20, name: 'เกราะมังกร', icon: '🐉', type: 'armor', def_bonus: 15, price: 350, lvl: 6 },

// เครื่องประดับ (4 ช่อง — ไม่มี classReq ใส่ได้ทุกคลาส)
{ id: 30, name: 'แหวนพลัง', icon: '💍', type: 'accessory', atk_bonus: 5, price: 200, lvl: 3 },
```

| field | ความหมาย |
|---|---|
| `type` | `weapon` / `armor` / `helmet` / `gloves` / `pants` / `boots` / `accessory` / `consumable` / `junk` |
| `classReq` | (ไม่บังคับ) array ของคลาสที่สวมได้ เช่น `['warrior', 'cleric']` |
| `handed` | (ไม่บังคับ) `1` = มือเดียว (ใส่มือหลักหรือมือรอง) · `2` = สองมือ (ปิดมือรอง) |
| `exclusive` | (ไม่บังคับ) `true` = ดรอปเฉพาะทาง (ไม่ดรอปตามปกติ) |
| `learn_skill` | (ไม่บังคับ) id ของสกิลที่เรียนเมื่อใช้ (คัมภีร์สกิล) — ถ้าเรียนแล้ว → ยกระดับคัมภีร์ (พลัง x1.1/ระดับ แยกจากเลเวลสกิล) |

**📜 คัมภีร์ / 📋 แบบแปลนซ้ำ = ยกระดับ (tier):**

- คัมภีร์สกิลซ้ำของสกิลที่เรียนแล้ว → ยกระดับคัมภีร์ **x1.1 ต่อระดับ** (ทบต้น ไม่จำกัด) — คูณรวมกับเลเวลสกิล (XP จากใช้สู้บอส)
- แบบแปลนซ้ำของสูตรที่เรียนแล้ว → ยกระดับสูตร — คราฟต์ได้ของ **x tier** (เช่น ระดับ 2 = คราฟต์ครั้งละ 2 ชิ้น)
- ระดับคัมภีร์/สูตรโชว์ในหน้าตัวละคร + แท็บคราฟต์ — เรียนครบทุกสกิล/สูตรแล้วยังหาของซ้ำได้จากสมบัติ/กล่องลึกลับเพื่ออัปเกรดต่อ

## 🤖 ระบบ LLM (เนื้อเรื่องสุ่มเสริม)

เกมเชื่อม **LLM** เขียน "เรื่องราวการผจญภัย" สั้น ๆ ลงในบันทึกหลังจบ session — เนื้อเรื่องไม่ซ้ำเดิม

> ⚠️ LLM เขียนแค่ **ข้อความบรรยายเท่านั้น** — XP/ทอง/ไอเทม/รางวัลทั้งหมดคำนวณที่ server ตามเดิม

### วิธีเปิดใช้

ค่า default ชี้ไป LLM ในเครื่อง (`localhost:8080/v1`) — **รันตามปกติได้เลย ไม่ต้องตั้ง env**:

```bash
npm run dev
```

ตั้งค่าเพิ่มเติม (ไม่บังคับ):

```bash
LLM_BASE_URL=http://localhost:8080/v1   # base URL (ค่า default)
LLM_MODEL=default            # ชื่อโมเดล (ค่า default: "default")
LLM_TIMEOUT_MS=30000         # timeout ต่อ request
LLM_ENABLED=0                # บังคับปิด LLM
```

### ใช้กับ g4f.space (remote)

- Bake proof-of-work ฟรีที่ `g4f.dev/chat` → credits ผูก IP → รันด้วย `LLM_ENABLED=1 npm run dev`
- หรือสมัคร `g4f.dev/members.html` เอา key มาใส่ `LLM_API_KEY`

| จุดที่ LLM ถูกใช้ | ผลลัพธ์ |
|---|---|
| หลังจบ work session (`/adventure/complete`) | เขียนเรื่องราว 2-3 ประโยคจากบริบท → บันทึกเป็น log "📖 เรื่องราวการผจญภัย" |

## ❓ คำถามที่พบบ่อย (FAQ)

### ❓ ทำไม LLM ไม่เขียนเรื่อง?
เกมมีการตั้งค่า LLM default ให้รันได้เลยทันทีที่ `npm run dev` หากต้องการใช้ LLM จากระบบภายนอก (เช่น g4f.space) ต้องตั้ง `LLM_ENABLED=1` และอาจต้องรับ Bake proof-of-work หรือใส่ API Key ผ่าน `.env` ค่ากำหนด default ชี้ไปที่ `localhost:8080/v1` จึงรันได้ทันทีโดยไม่ต้องตั้งค่าอะไร

### ❓ วิธีติดตั้ง PWA บนมือถือ?
เปิดเว็บใน Chrome บนมือถือ → เมนู (⋮) → **Add to Home Screen** → กด "Add" → จะแสดงเป็นแอพบนหน้าจอเหมือนแอพจริง สามารถเปิดได้แม้ไม่มีอินเทอร์เน็ต (ถ้า PWA ถูกติดตั้งถูกต้อง) สำหรับ iOS (Safari) ให้ใช้ "Add to Home Screen" ในเมนูเบราว์เซอร์เช่นกัน

### ❓ session หาย/รีเซ็ต?
การรีเซ็ตเกิดขึ้นได้จากการรันคำสั่ง `./run.sh reset` ซึ่งจะหยุด server ลบฐานข้อมูลและเริ่มใหม่ทั้งหมด หาก session หายโดยบังคับ อาจเป็นเพราะฐานข้อมูลถูกลบหรือโปรเจกต์ถูกรีสตาร์ท สามารถกู้คืนได้จาก `./run.sh restore` โดยใช้ไฟล์backup `.db` หรือ `.json.gz`

### ❓ กระเป๋าเต็ม?
เมื่อกระเป๋า 20 ช่องเต็มและรับของรางวัลใหม่ เกมจะอัตโนมัติขายของ junk ทิ้ง (รับซื้อ +25%) และบล็็อกไม่ให้เก็บของเพิ่มได้ สามารถขายของ handbook ได้ที่ตลาดมืด หรือจัดการจัดสรรช่องว่างก่อนรับรางวัลใหม่

### ❓ ทำไมไม่มี shields.io บน badges?
โปรเจกต์ไม่ได้接入 shields.io บริการจริง แต่สร้าง badges ขึ้นมาเองในรูปแบบ Text เพื่อให้สอดคล้องกับแบรนด์และไม่พึ่งพาบริการภายนอก
