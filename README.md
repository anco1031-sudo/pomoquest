# 🍅⚔️ PomoQuest — Pomodoro RPG

โฟกัสงาน… แล้วตัวละครของคุณจะผจญภัยไปกับคุณ!

PomoQuest ผสม **เทคนิค Pomodoro** เข้ากับ **เกม RPG** — ทุกครั้งที่คุณตั้งใจโฟกัสงาน ตัวละครของคุณจะออกเดินทางผจญภัย เก็บเลเวล ต่อสู้กับมอนสเตอร์ หาสมบัติ สู้กับบอส และเดินทางข้ามเมืองไปเรื่อย ๆ

## 🎮 แนวคิดการเล่น

| ช่วงเวลา | สิ่งที่เกิดขึ้นในเกม |
|---|---|
| **Work session (25 นาที)** | ⚔️ ผจญภัยในเมืองปัจจุบัน — ทุก ~90 วินาทีจะเกิดเหตุการณ์สุ่ม: เจอมอนสเตอร์ (สู้แบบอัตโนมัติ ไม่รบกวนสมาธิ) เจอสมบัติ ศาลเจ้าลึกลับ พ่อค้าเร่ร่อน หรือกับดัก |
| **พักสั้น (5 นาที)** | 🔥 ค่ายพัก — ซื้อของที่ร้านค้า ทำภารกิจย่อย (สำเร็จ/เสี่ยง) ใช้ไอเทม ฟื้นพลังฟรี หรือจัดสรรแต้มสถานะ |
| **ครบ 4 sessions** | 👹 **พักยาว (15 นาที) = สู้บอส!** ต่อสู้แบบเทิร์น-by-เทิร์น (โจมตี/สกิล/ใช้ยา) ชนะแล้วได้รางวัลใหญ่และเดินทางสู่เมืองถัดไป |

### ระบบหลัก
- 🧑‍🎤 **สร้างตัวละครหลายตัว** — เลือกชื่อ + 1 ใน 4 คลาส (นักรบ / นักเวทย์ / โจร / นักบวช) สร้างได้หลายตัว สลับเล่นได้ เปลี่ยนชื่อได้ (ห้ามชื่อซ้ำ) ลบได้ (ปุ่ม 👥 + ยืนยัน 2 ครั้งกันลบพลาด) แต่ละตัวมี progress/ไอเทม/timer แยกกัน
- 📈 **เลเวล & แต้มสถานะ** — สะสม XP เพื่อเลเวลอัพ ได้แต้มจัดสรรเอง (HP / MP / ATK / DEF / SPD) พร้อมการเติบโตอัตโนมัติ
- 🎒 **ไอเทม & อุปกรณ์** — ยารักษา, อาวุธ, เกราะ, เครื่องประดับ (ซื้อ/ขาย/สวม/ใช้)
- 🔥 **คอมโบโฟกัส** — ทำ session ต่อเนื่องไม่ทิ้ง ได้โบนัส XP สูงสุด x1.5
- 🗺️ **8 เมือง** — ชนะบอสทีละเมืองเพื่อเดินทางต่อไป (บอสและมอนสเตอร์แข็งแกร่งขึ้นตามเลเวล) และ **เดินทางย้อนกลับ** ไปเมืองที่เคยไปมาแล้วได้ (เสีย 20 ทอง/เมือง — ไปข้างหน้าต้องชนะบอสเท่านั้น)
- 📅 **Daily Quest (ภารกิจประจำวัน)** — สุ่ม 3 ภารกิจต่อวัน (รีเซ็ตเที่ยงคืน) เช่น โฟกัสครบ 2 session, กำจัดมอนสเตอร์ 5 ตัว, ชนะบอส 1 ตัว — ทำเสร็จแล้ว**เลือกรางวัลเองได้** (ทอง / XP / ไอเทมสุ่ม) และทำครบทุกภารกิจได้โบนัสพิเศษ (ทอง + XP + ไอเทม) พร้อม **streak ภารกิจ**: ทำครบติดต่อกันหลายวัน โบนัสเพิ่ม 20%/วัน สูงสุด x2
  - **ไอเทมพิเศษ (✦ พิเศษ)** — ของ Exclusive 5 อย่างที่หาซื้อตามร้านไม่ได้ (ถุงเงินนำโชค, คัมภีร์ประสบการณ์, สมุดนำโชค, มงกุฎนักโฟกัส, อีลิกเซอร์บริสุทธิ์) ได้จากการเลือกรางวัล "ไอเทมสุ่ม" (40%) หรือโบนัสครบทุกภารกิจ (35%) เท่านั้น
- 🏅 **ระบบ Achievement (40 ตรา: ปกติ 25 + ลับ 15)** — ปลดล็อกอัตโนมัติเมื่อถึงเงื่อนไข ได้รางวัลทอง/XP ดูความคืบหน้าได้ที่แท็บ "ตรา"
  - **ตราปกติ** — session, บอส, มอนสเตอร์, สมบัติ, ภารกิจ, คอมโบ, เลเวล, ทอง ฯลฯ (โชว์ความคืบหน้า)
  - **ตราลับ** — เงื่อนไขซ่อนไว้ (โชว์เป็น "???" พร้อมคำใบ้ลึกลับ เช่น โฟกัสตอนตี 2, ชนะบอสตอน HP=1, สู้บอสโดยไม่สวมอุปกรณ์, พิชิตครบ 8 เมือง) รางวัลสูงกว่า
- 📊 **หน้า Stats** — กราฟโฟกัสย้อนหลัง 7 วัน, เวลาโฟกัสสะสม, สถิติต่อสู้ (มอนสเตอร์/สมบัติ/ภารกิจ/บอส), เส้นทางการเดินทางข้ามเมือง
- 📜 **บันทึกการผจญภัย** — ดูประวัติทุกเหตุการณ์ รางวัล และสถิติสะสม
- 📱 **PWA** — ติดตั้งเป็นแอพบนมือถือได้ (Add to Home Screen) ใช้งานแบบ standalone

## 🛠️ Tech Stack

- **Frontend:** React 19 + Vite (mobile-first CSS, ไม่มี UI framework)
- **Backend:** Express
- **Database:** SQLite (better-sqlite3) — เก็บที่ `server/data/pomoquest.db`
- **PWA:** manifest + service worker (network-first) + ไอคอน PNG สร้างจาก pixel art

## 🚀 วิธีรัน

**รันง่ายด้วย script** (ดูวิธีใช้เต็ม: `./run.sh help`):

```bash
./run.sh            # โหมดพัฒนา (server :3001 + frontend :5173)
./run.sh prod       # build + รัน production ที่ http://localhost:3001
./run.sh start      # รัน production แบบ background (log: /tmp/pomoquest.log)
./run.sh stop       # หยุด server
./run.sh status     # ดูสถานะ server + LLM
./run.sh llm        # เช็คว่า LLM ที่ localhost:8080 พร้อมใช้ไหม
```

หรือรันด้วย npm ตรง ๆ:

```bash
npm install          # ติดตั้ง dependencies (ครั้งแรก)
npm run dev          # โหมดพัฒนา — server :3001 + frontend :5173 (เปิด http://localhost:5173)
```

โหมด production:

```bash
npm run build        # build frontend ไปที่ dist/
npm start            # รัน server เดียว เสิร์ฟทั้งแอพที่ http://localhost:3001
```

> 💡 บนมือถือ: เปิดเว็บใน Chrome → เมนู → **Add to Home Screen** → ใช้งานเหมือนแอพจริง

## ➕ เพิ่มเนื้อหาเกมเอง (มอนสเตอร์ / อุปกรณ์ / เมือง)

ข้อมูลเกมทั้งหมดอยู่ในไฟล์เดียว: **`server/data.js`** — เกม engine อ่านจาก array เหล่านี้โดยตรง ดังนั้น **เพิ่มเนื้อหาใหม่ไม่ต้องแตะโค้ดอื่นเลย** (ไม่ต้องแก้ engine, API หรือ UI) เปิดแอพใหม่แล้วใช้งานได้ทันที

### 🐾 เพิ่มมอนสเตอร์

เพิ่ม entry ใน `MONSTERS` array:

```js
{ name: 'กอร์กอน', icon: '🐍', power: 1.4, xp: 48, gold: 30 },
```

| field | ความหมาย |
|---|---|
| `name` / `icon` | ชื่อและอีโมจิแสดงผล |
| `power` | ตัวคูณพลังตามเลเวลตัวละคร (0.7 = อ่อน, 1.5 = แรง) — ยิ่งสูงยิ่งชนะยาก |
| `xp` / `gold` | รางวัลพื้นฐานตอนชนะ (ได้เพิ่มตามเลเวลอัตโนมัติ) |

### ⚔️ เพิ่มอุปกรณ์ / ไอเทม

เพิ่ม entry ใน `ITEMS` array — มี 3 ประเภทหลัก (ดูจาก `type`):

```js
// อาวุธ / เกราะ / เครื่องประดับ (สวมใส่ได้)
{ id: 14, name: 'ดาบเพลิง', icon: '🔥', type: 'weapon', atk_bonus: 12, price: 260, desc: 'ดาบที่ร้อนแรง', lvl: 4 },

// ของใช้ (กิน/ใช้แล้วหาย) — heal_pct / mana_pct / use_gold / use_xp
{ id: 45, name: 'ยามหัศจรรย์', icon: '🍯', type: 'consumable', heal_pct: 0.5, mana_pct: 0.3, price: 90, desc: 'ฟื้น HP 50% และ MP 30%' },
```

| field | ความหมาย |
|---|---|
| `id` | **ต้องไม่ซ้ำกัน** (ระบบใช้ id เป็น key) — ตอนนี้ใช้ 1-4 ยา, 10-13 อาวุธ, 20-23 เกราะ, 30-33 เครื่องประดับ, 40-44 exclusive |
| `type` | `weapon` / `armor` / `accessory` (อุปกรณ์) หรือ `consumable` (ของใช้) |
| โบนัส | ตามประเภท: `atk_bonus` `def_bonus` `hp_bonus` `mp_bonus` `spd_bonus` `crit_bonus` (อุปกรณ์), `heal_pct` `mana_pct` `use_gold` `use_xp` (ของใช้) |
| `lvl` | ระดับขั้นต่ำที่สวม/ดรอปได้ (อุปกรณ์) — ดรอปต้อง `lvl ≤ เลเวลตัวละคร + 1` |
| `price` / `desc` | ราคาขายในร้านและคำอธิบาย |
| `exclusive: true` | **(ไม่บังคับ)** ตั้งไว้ = ไอเทมพิเศษเฉพาะ Daily Quest — **ร้านค้าไม่ขาย** และไม่ดรอปตามปกติ (ได้จากการเลือกรางวัล "ไอเทมสุ่ม" / โบนัสครบภารกิจเท่านั้น) |

### ⚠️ ข้อควรรู้

- **ร้านค้า:** ขายอุปกรณ์ทุกชิ้นที่ `ไม่ใช่ exclusive` อัตโนมัติ แต่ **ของใช้ (consumable) ขายเฉพาะ id 1-4** — ถ้าอยากขายยาตัวใหม่ในร้าน ต้องเพิ่ม id ในเงื่อนไข `SHOP_STOCK` (บรรทัดเดียวกับนิยาม `SHOP_STOCK` ใน `data.js`)
- **การดรอป:** เกมสุ่มดรอปตามระดับ — อุปกรณ์ `lvl` สูงเกินเลเวลตัวละครจะยังไม่ดรอป (ตั้งใจให้เป็นของหายาก)
- **exclusive:** ไอเทม `exclusive: true` จะถูกกรองออกจากร้านและดรอปทั้งหมดอัตโนมัติ — ใช้สำหรับของ Daily Quest เท่านั้น
- **เมือง & บอส:** เพิ่มได้เหมือนกัน (เพิ่ม `CITIES` + `BOSSES` คู่กัน จำนวนต้องเท่ากัน เพราะบอสผูก index กับเมือง) — แต่ระวังตราลับ "ผู้พิชิตแอสการ์ด" ที่ผูกกับ index เมืองที่ 8 (แก้ใน `data.js` → `SECRET_ACHIEVEMENTS` ได้)

## 🤖 ระบบ LLM (เนื้อเรื่องสุ่มเสริม)

เกมสามารถเชื่อม **LLM** เพื่อเขียน "เรื่องราวการผจญภัย" สั้น ๆ ลงในบันทึกหลังจบแต่ละ session (📖 เรื่องราวการผจญภัย) — เนื้อเรื่องไม่ซ้ำเดิมทุกครั้ง ภาษาไทยปนอังกฤษตามสไตล์เกม

> ⚠️ LLM เขียนแค่ **ข้อความบรรยายเท่านั้น** — XP/ทอง/ไอเทม/รางวัลทั้งหมดยังคำนวณที่ server ตามเดิม (กันโกง + กัน balance พัง) และ **ถ้าไม่มี key หรือ API error เกมจะใช้ข้อความตายตัวเดิมปกติ** ไม่พัง

### วิธีเปิดใช้ — ค่า default ชี้ไป LLM ในเครื่อง (`localhost:8080/v1`)

**รันตามปกติได้เลย ไม่ต้องตั้ง env อะไร** — โมดูลจะเรียก `http://localhost:8080/v1/chat/completions` ด้วย `model: "default"` โดยอัตโนมัติ (กรณี base URL เป็น localhost เกมจะเปิดใช้ LLM เอง ไม่ต้อง auth):

```bash
npm run dev
```

> ตัวอย่าง: รัน g4f instance / Ollama / LLM server ใดก็ได้ที่ OpenAI-compatible ไว้ที่ port 8080 (เช่น `g4f` local: `python -m g4f`)

ตั้งค่าเพิ่มเติม (ไม่บังคับ):

```bash
LLM_BASE_URL=http://localhost:8080/v1   # base URL ของ API (ค่า default)
LLM_MODEL=default            # ชื่อโมเดล — ค่า default คือ "default"
LLM_TIMEOUT_MS=30000         # timeout ต่อ request (เผื่อ cold start โมเดล local)
LLM_ENABLED=0                # บังคับปิด LLM (ไม่เรียกเลย)
```

### ใช้กับ g4f.space (remote — ต้อง auth)

- **g4f.space ตรวจ credits ฝั่ง backend** — ต่อให้ใช้ `g4f.dev/dist/js/client.js` ใน browser ตรง ๆ ก็เจอ error `402 No cake credits` ถ้าเครื่องยังไม่มี credits (ทดสอบจริงแล้ว)
- วิธีใช้: bake proof-of-work ฟรีที่ `g4f.dev/chat` → credits ผูกกับ IP → รันด้วย `LLM_ENABLED=1 npm run dev` (ไม่ต้อง key) หรือสมัคร `g4f.dev/members.html` เอา key มาใส่ `LLM_API_KEY`

```bash
LLM_ENABLED=1 npm run dev          # credits ผูก IP (bake ฟรีแล้ว)
LLM_API_KEY=xxxx npm run dev       # มี key
```

### จุดที่ LLM ถูกใช้ตอนนี้

| จุด | ผลลัพธ์ |
|---|---|
| หลังจบ work session (`/adventure/complete`) | เขียนเรื่องราว 2-3 ประโยคจากบริบท (ตัวละคร/เมือง/เวลาที่โฟกัส/คอมโบ) → บันทึกเป็น log "📖 เรื่องราวการผจญภัย" |

## 🔌 API หลัก

| Method | Path | ความหมาย |
|---|---|---|
| GET | `/api/state` | สถานะรวม (ตัวละคร, สถิติ, กระเป๋า, บันทึก, ตั้งค่า) |
| POST | `/api/character/create` | สร้างตัวละคร (หลายตัวได้) |
| POST | `/api/character/select` · `/rename` · `/delete` | เลือก / เปลี่ยนชื่อ / ลบตัวละคร |
| GET | `/api/characters` | รายชื่อตัวละครทั้งหมด |
| GET | `/api/stats` | สถิติละเอียด (กราฟ 7 วัน + สถิติต่อสู้) |
| POST | `/api/adventure/event` | สุ่มเหตุการณ์ระหว่าง work session |
| POST | `/api/adventure/complete` | จบ session → แจกรางวัล + คอมโบ |
| GET | `/api/camp` | ร้านค้า + ภารกิจ (ช่วงพัก) |
| POST | `/api/shop/buy` · `/api/quest/do` | ซื้อของ / ทำภารกิจ |
| GET/POST | `/api/boss` · `/api/boss/act` | สู้บอส (โจมตี/สกิล/ยา) |
| POST | `/api/character/allocate` | จัดสรรแต้มสถานะ |
| POST | `/api/travel` | เดินทางย้อนกลับไปเมืองที่เคยไปมาแล้ว (เสีย 20 ทอง/เมือง) |
| PUT | `/api/settings` | ปรับเวลา Pomodoro |
