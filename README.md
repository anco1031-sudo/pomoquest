# 🍅⚔️ PomoQuest — Pomodoro RPG

> โฟกัสงาน… แล้วตัวละครของคุณจะผจญภัยไปกับคุณ!

PomoQuest ผสม **เทคนิค Pomodoro** เข้ากับ **เกม RPG** — ทุกครั้งที่คุณตั้งใจโฟกัสงาน ตัวละครของคุณจะออกเดินทางผจญภัย เก็บเลเวล ต่อสู้กับมอนสเตอร์ หาสมบัติ สู้กับบอส และเดินทางข้ามเมืองไปเรื่อย ๆ

**React 19** · **Express** · **SQLite** · **PWA** · ⚔️ 4 คลาส · 🗺️ 12 เมือง · 🔥 โหมดท้าทาย · 🏅 54 ตรา · 📅 Daily Quest · 🤖 LLM เรื่องราว

## 🎮 แนวคิดการเล่น

| ช่วงเวลา | สิ่งที่เกิดขึ้นในเกม |
|---|---|
| **Work session (25 นาที)** | ⚔️ ผจญภัยในเมืองปัจจุบัน — ทุก 30–90 วินาที (สุ่ม) จะเกิดเหตุการณ์สุ่ม: เจอมอนสเตอร์ (สู้แบบอัตโนมัติ ไม่รบกวนสมาธิ) เจอสมบัติ ศาลเจ้าลึกลับ พ่อค้าเร่ร่อน หรือกับดัก — **ระหว่างโฟกัสไม่เด้ง modal** (ไม่บล็อกหน้าจอ) เห็นแค่ toast สรุปรางวัล (แบบคิว — โชว์เรียงกัน ไม่ทับกัน) + log เหตุการณ์ย้อนหลัง (เรียงล่าสุดบนสุด พร้อมเวลา) และ **สรุป session** รวมของรางวัลทุกเหตุการณ์ตอนจบ session |
| **พักสั้น (5 นาที)** | 🔥 ค่ายพัก — ซื้อของที่ร้านค้า ทำภารกิจย่อย (สำเร็จ/เสี่ยง) ใช้ไอเทม ฟื้นพลังฟรี หรือจัดสรรแต้มสถานะ |
| **ครบ 4 sessions** | 👹 **พักยาว (15 นาที) = สู้บอส!** ต่อสู้แบบเทิร์น-by-เทิร์น (โจมตี/🛡️ ตั้งรับ/สกิล/ใช้ยา) — บอสมี 2 เฟส (โกรธจัดตอน HP ≤ 50%) + ชาร์จท่าไม้ตายให้สลาย/ตั้งรับ ชนะแล้วได้รางวัลใหญ่และเดินทางสู่เมืองถัดไป |

## ⭐ ระบบหลัก

### 🧑‍🎤 ตัวละคร

- **สร้างได้หลายตัว** — เลือกชื่อ + 1 ใน 4 คลาส (นักรบ / นักเวทย์ / โจร / นักบวช) สลับเล่นได้ เปลี่ยนชื่อได้ (ห้ามชื่อซ้ำ — แจ้งเตือน inline ใต้ช่องชื่อ) ลบได้ (ปุ่ม 👥 + ยืนยัน 2 ครั้งกันลบพลาด)
- 🎭 **จุดเด่น/จุดด้อยเฉพาะคลาสตามช่วงเวลา** (☀️ 06:00–17:59 / 🌙 18:00–05:59 ตามเวลาจริงของเครื่อง) — ⚔️ **นักรบ**: กลางวันมอนสเตอร์อ่อนลง 15% + เจอบ่อยขึ้น + ตีบอส +10% / กลางคืนมอนสเตอร์แข็งขึ้น 15% + ตีบอส -10% · 🔮 **นักเวทย์**: กลางคืน XP +25% + ตีบอส +10% / กลางวัน XP -10% + ตีบอส -10% (พลังจันทรา) · 🗡️ **โจร**: กลางคืนทอง +30% + เจอสมบัติ x1.25 + ตีบอส +10% แต่กับดักถี่ขึ้น x1.3 (มืดมองไม่เห็น!) · ✨ **นักบวช**: กลางวันศาลเจ้า ⛩️ ถี่ขึ้น x1.25 + รางวัล +25% + ตีบอส +10% / กลางคืนมอนสเตอร์แข็งขึ้น 10% — โชว์บนการ์ดคลาสตอนสร้าง + แผ่นตัวละคร (ไฮไลต์ช่วงเวลาปัจจุบัน)
- แต่ละตัวมี **progress / ไอเทม / timer แยกกัน**

### 🔥 โหมดท้าทาย

- เลือกตอนสร้างตัวละคร — **เปลี่ยนระหว่างเล่นได้** ด้วยปุ่ม 🔄 เปลี่ยนโหมด (เสียค่าปรับทอง 50+30×เลเวล + คอมโบรีเซ็ต กันสลับเก็บโบนัส)
- ทุกโหมดได้รางวัล XP/ทอง **x1.5** + ตราลับเฉพาะโหมด:

| โหมด | กติกา |
|---|---|
| ⚔️ **โหมดโหด** | มอนสเตอร์/บอสแรงขึ้น x1.3 · ดรอปของยากขึ้น (x0.6) · ราคาร้าน/ตลาดมืดแพงขึ้น x1.3 |
| ⏱️ **โหมดมาราธอน** | ห้ามพักระหว่างโฟกัส — โฟกัสไม่ถึง 90% ของเวลาที่ตั้ง → session "เสีย" (ไม่ได้รางวัล ไม่นับ session คอมโบหาย) |
| 🩸 **โหมดเอาชีวิตรอด** | พักแคมป์ไม่ฟื้น HP/MP ฟรี (ต้องใช้ยา/สมุนไพร) · HP เหลือ 1 ตอนจบ session → "อ่อนแรงล้ม": เสียของสุ่ม 1 ชิ้น + คอมโบหาย (ยังได้ XP/ทอง session เพราะโฟกัสงานครบ) |

### ⏸️ พักกลาง session

- กด **⏸️ หยุดพัก** หรือ **🏠 กลับหน้าหลัก** กลาง session = **พักจริง ๆ** — timer หยุด ไม่สะสม XP/เลเวล ไม่มี modal เด้งมารบกวน (ถึงรีโหลดหน้าก็ยังพักอยู่ ไม่รันต่อเอง)
- กด **⏸️ หยุดพัก** หรือ **🏠 กลับหน้าหลัก** แล้ว **เลือกได้ 2 แบบ**: **⏸️ พักสั้น (นับเวลา)** — เหมาะเข้าห้องน้ำ/รับสาย · **😴 พักยาว (แยกหมวดสถิติ)** — เหมาะนอน/ทานข้าว/ธุระยาว (**เลือกชื่อสำเร็จรูป** เช่น 🍚 กินข้าว / 😴 นอนกลางวัน / 🌙 นอนกลางคืน / 🎲 ทำอย่างอื่น หรือพิมพ์เอง — ขึ้นใน log + รวมสถิติแยกตามชื่อในหน้า Stats): timer หยุดเหมือนกัน แต่เวลาพักยาว**แยกหมวด "พักยาว" ในสถิติ** (ไม่ปนกับ "พักกลาง session") — กลับมาแล้ว modal ถาม **โฟกัสต่อ / ทิ้ง session** (โชว์เวลาที่ไม่อยู่ + ชื่อพัก) · โหมดมาราธอนยังถือว่าพัก (ทั้งสั้นและยาว) = เสีย session เหมือนเดิม
- **นับเวลาพักแยกต่างหาก** จากพักเบรกระหว่าง session — พักสั้น (⏸️) กับพักยาว (😴) แยกหมวดกัน — ดูได้ในหน้า Stats (ยอดรวม + กราฟ 7 วัน) และใน log จบ session
- กลับมาแล้วกด **▶️ โฟกัสต่อ** จากแถบ sticky ด้านบนของหน้า Home (โชว์ชื่องาน/เวลาที่เหลือ/เวลาพัก — มีปุ่มทิ้ง session ด้วย)
- **Reset/ล้างข้อมูล = session ที่พักค้างหายไปด้วย** — เกมผูก session กับ "โลกเวอร์ชัน" (epoch) ที่ server: ล้างข้อมูลผ่านปุ่มในเกม, `./run.sh reset` (ลบ DB), หรือกู้คืน backup → epoch เปลี่ยน → session ที่พักค้างในเครื่อง (localStorage) ถูกทิ้งอัตโนมัติ ไม่หลุดกลับมาให้ใหม่ตัวละคร id เดิม

### 📈 เลเวล & แต้มสถานะ

- สะสม XP เพื่อเลเวลอัพ ได้แต้มจัดสรรเอง (HP / MP / ATK / DEF / SPD) พร้อมการเติบโตอัตโนมัติ
- ปุ่ม **"จัดอัตโนมัติ"** แจกแต้ม **ตามน้ำหนักเฉพาะคลาส** (นักรบเน้น HP/ATK/DEF · นักเวทย์เน้น MP/ATK · โจรเน้น SPD/ATK · นักบวชเน้น HP/MP/DEF) **และปรับตามอุปกรณ์ที่สวม** — stat ที่เกียร์ให้อยู่แล้วจะได้น้ำหนักลดลง แต้มไปเติม stat ที่ขาด (เช่น สวมเกราะ DEF เยอะ → ไปเพิ่ม ATK/HP)
- **รวมถึงของในกระเป๋าที่สวมได้แต่ขาด stat** — alloc จะเติม stat ให้ถึงเกณฑ์ (เช่น ATK 20+ เพื่อสวมดาบ) ก่อน แล้วค่อยกระจายแต้มที่เหลือตามคลาส พร้อมโชว์เป้าหมายใน hint (เช่น "🎯 เป้าหมาย: 🗡️ ดาบเป้าหมาย (ATK +6)")
- 🔍 **โหมดวางแผน** — กดดูผลลัพธ์ก่อนยืนยัน (dry-run): โชว์แผนแนะนำ + stat ก่อน/หลัง + ของที่จะสวมได้ใหม่ + ของที่ยังสวมไม่ได้พร้อมเหตุผล — ปุ่ม "✨ จัดตามแผนนี้" ตั้งแต้มตามแผนแนะนำทันที (ยังไม่บันทึกจนกว่าจะกดยืนยัน)

### 🎒 ไอเทม & อุปกรณ์ (RPG)

- ระบบช่องสวมใส่ **11 ช่อง**: อาวุธมือหลัก/มือรอง (มือรองใส่ได้ทั้งอาวุธมือเดียวหรือโล่ — อาวุธสองมือจะปิดช่องมือรอง), หมวก (หัว), เกราะ (ตัว), แขน, ขา, เท้า และเครื่องประดับ 4 ช่อง (ซื้อ/ขาย/สวม/ถอด/ใช้)
- อุปกรณ์มี **ข้อจำกัดการสวม**: บางชิ้นเฉพาะคลาส (ป้าย 🎭 สีประจำคลาส: แดง=นักรบ, ฟ้า=นักเวทย์, เทา=โจร, เขียว=นักบวช), ต้องเลเวลขั้นต่ำ (🔒เลเวล X+), หรือต้องมีค่าสถานะถึงเกณฑ์ (🔒 ATK/DEF/SPD/MP X+) — ดูได้จากชิปที่ไอเทม ปุ่มสวมจะปิดพร้อมบอกเหตุผล (ร้านค้า/ดรอป/รางวัล Daily Quest กรองของเฉพาะคลาสอื่นออกให้อัตโนมัติ)
- 🐾 **ล่าได้ของ** — ชนะมอนสเตอร์ ~40% ได้ของขวัญประจำตัว (ฟันหนูยักษ์/ปีกค้างคาว/เกล็ดมังกรน้อย ฯลฯ — ราคาต่ำ) · 👹 **ชนะบอส ~50% ได้ของรางวัลประจำตัว** (ตราโจรป่า/หัวใจจอมมาร ฯลฯ — ขายแพงกว่า) — ทั้งหมดนับรวมในเควสประจำวัน "คนเก็บขยะ"
- 📖 **คู่มือล่า** (แท็บสถิติ) — ตารางมอนสเตอร์ 8 ตัว + บอส 12 ตัว พร้อมของที่ดรอป (ไอคอน/ชื่อ/ราคา) ให้วางแผนล่าของได้
- 🏷️ **ราคาร้านตามวัน** — ของที่พ่อค้าต้องการวันนี้ (🔥 สุ่มรายวัน เปลี่ยนทุกวัน — ระบบเดียวกับราคาขาย) แพงขึ้น · ของส่วนใหญ่ราคาปกติ · มีสุ่มไม่กี่ชิ้นที่ลดราคา (🏷️) · **ราคาขาย** ตามที่พ่อค้าแคมป์รับซื้อ (ของที่ต้องการขายได้แพงขึ้น)
- 🎁 **ของแถมฟรี** — สุ่มรายค่ายพัก (~35% โอกาสเจอ 1 ชิ้น) ที่พ่อค้า/ตลาดมืด "ไม่อยากได้" → ราคา 0 ยกให้ฟรี (deterministic จากค่ายพัก — เปิดซ้ำหน้าเดิมได้ของเดิม · ของพิเศษ exclusive กับของเทศกาลไม่สุ่มให้ฟรี)
- 🛠️ **คราฟต์จากของขวัญ** — แท็บใหม่ในค่ายพัก: เรียนรู้สูตรจาก **แบบแปลน 📋** (ดรอปจากกล่องสมบัติ — โอกาสสูงกว่าใบสกิลนิดหน่อย — และการันตีจากบอสเร่ร่อน 🐉) แล้วใช้เรียนรู้เหมือนคัมภีร์สกิล → คราฟต์ junk เป็นยา/เกราะมังกรได้ที่แท็บ 🛠️ คราฟต์ (ไม่เสียทอง ต้องมีวัสดุ)
- 🐾 **ระบบสัตว์เลี้ยง (Pet)** — ฟักจาก **🥚 ไข่ปริศนา** (ดรอปหายาก ~4% จากกล่องสมบัติ + event พิเศษ "🥚 ไข่ปริศนา") — ไข่ไม่สปอยล์ (hover เห็นแค่ "ไข่ปริศนา" จนกว่าจะฟัก) → **ใช้ไข่ = เริ่มฟัก** (ป้าย "🥚 กำลังฟัก…" บน Home) **จบ 1 session โฟกัส ไข่ถึงจะฟัก** → สุ่ม 1 ใน 8 ตัวตาม rarity (ทั่วไป 60% / หายาก 28% / หายากมาก 10% / ตำนาน 2%): หนูแฮมสเตอร์/ลูกเจี๊ยบ/จิ้งจอกเงิน/นกฮูกจอมยุทธ์/งูเหลือมทอง/แมวซน/มังกรน้อย/ยูนิคอร์น — **แต่ละตัวมีค่าพิเศษเฉพาะ** (+% ทอง/XP, เจอมอนสเตอร์/สมบัติ/ศาลเจ้าถี่ขึ้น, แมวซนเจอกับดักถี่ x1.5 แต่ 40% ขโมยของกลับมาได้, ยูนิคอร์นกันกับดัก 1 ครั้ง/รอบ) — **เลเวล pet** เพิ่มจากโฟกัส + ร่วมผจญภัย (ค่าพิเศษ +10%/เลเวล) — **ฟองอารมณ์** ตามวันไม่ได้โฟกัส (😄→🥺)
- 🐾 **คอกสัตว์ (Stable)** — เริ่ม 1 ช่อง สูงสุด 4: ตัวที่ **ใช้งาน (active)** เท่านั้นที่ค่าพิเศษมีผล · สลับตัวได้ฟรี · คอกเต็มต้องปล่อยตัวหนึ่งก่อน (ได้ทองปลอบใจ) · ขยายช่องด้วย **💳 บัตรขยายคอก** (ดรอปหายากมากจากสมบัติ ~1% + **บอสลับการันตีใบแรก**)
- 🎒 **กระเป๋า (Bag)** — ลิมิต **20 ช่อง** (ของแต่ละชนิด = 1 ช่อง · ไอเทมซ้ำรวมกอง ไม่กินช่องเพิ่ม) — กันเก็บของไว้รอวันพ่อค้าต้องการไม่อั้น:
  - กระเป๋าเต็ม + รับของรางวัล/ดรอป (event/บอส/เควสต์/รางวัลรายวัน) → **ขายอัตโนมัติราคาพื้นฐาน** (ได้ทองทันที แต่ไม่รอราคาดี — จูงใจให้ขายเองที่แคมป์ก่อน)
  - กระเป๋าเต็ม + **ซื้อของ / คราฟต์** → **บล็อก** "🎒 กระเป๋าเต็ม — ขายของก่อน" (ของหายากราคา 0 เช่น ไข่🥚/บัตรขยายคอก💳 เข้ากระเป๋าได้เสมอ)
  - แถบความจุในหน้าของ (เขียว → เหลืองใกล้เต็ม → แดงเต็ม) + โชว์ X/20
- 💰 **ขายของหลายชิ้น** — ของชนิดเดียวกันซ้ำเกิน 1 ชิ้น กดขายจะถามจำนวนที่จะขายก่อน (กด +/− เลือกจำนวน)
- 🗺️ **ราคาขายตามเมือง** — เมืองยิ่งไกล พ่อค้ารับซื้อแพงขึ้น **(x1.05/เมือง)** (เมือง 12 ขายได้ ~x1.55) — จูงใจถือของไปขายเมืองไกล
- 🔍 **เทียบอุปกรณ์กับที่สวม** — ในร้านค้า/ตลาดมืด เกียร์ทุกชิ้นมีปุ่ม "🔍 เทียบกับที่สวม" กดแล้วเห็นช่องที่ไป + ของที่สวมอยู่ (หรือว่าง) + ค่า stat ทีละตัว เทียบของใหม่ → ของเก่า พร้อมผลต่าง ▲/▼ (เขียว=ดีขึ้น, แดง=แย่ลง) — ตัดสินใจซื้อง่ายขึ้น
- 🔔 **toast ยืนยันการซื้อ/ขาย** — ซื้อ: "ซื้อ X สำเร็จ (-Y ทอง)" · ขาย: "ขายได้ +Y ทอง" — ตัวเลขเครื่องหมายตรงกับทิศทางทองที่เปลี่ยน

### 🖤 ตลาดมืด

- เจอสุ่ม ~25% ต่อค่ายพัก (พ่อค้าเงาลึกลับ) — **รับซื้อของขวัญ (junk) แพงกว่าปกติ +25%** และขายของ 4 ชิ้นราคาลดพิเศษ (เลือก "สำรวจเมืองเดิมต่อ" หลังชนะบอส → โอกาสเจอเพิ่มขึ้น):
  - 📜 คัมภีร์สกิล (ลด 15%) · 💎 ของหายาก (ลด 25%) · 🎲 ของเถื่อนเก็งกำไร (ลด 45% — เก็บไว้ขายค่ายหน้าที่พ่อค้าต้องการ) · ✨ **ของพิเศษ exclusive ที่หลุดมาจาก Daily Quest** (ลด 10% — ยกเว้นถุงเงินนำโชค กันวนซื้อแล้วใช้ +150 ทอง) · 📦 **กล่องลึกลับ** (ราคาเต็ม 180) — ซื้อแล้วเปิดเลย สุ่มของคุ้ม/เจ๊ง (คัมภีร์สกิล 5% / ของหายาก 20% / เกียร์ 25% / ยา 50% — deterministic จากค่ายพัก เปิดซ้ำได้ของเดิม)
- ซื้อได้ครั้งเดียวต่อค่ายพัก หน้าเดิมเปิดซ้ำ ของ/ราคาเหมือนเดิม · การซื้อ/ขายกับตลาดมืดนับใน **ภารกิจประจำวัน "ลูกค้าตลาดมืด"** + ตรา 🖤/👑 · ถ้าเจอตลาดมืด พ่อค้าทั่วไปจะปิดร้าน (มีเพียงตลาดมืด) และบางชิ้นตลาดมืดไม่อยากได้ → ยกให้ฟรี 🎁

### 📅 Daily Quest (ภารกิจประจำวัน)

- สุ่ม 3 ภารกิจต่อวัน (รีเซ็ตเที่ยงคืน) เช่น โฟกัสครบ 2 session, กำจัดมอนสเตอร์ 5 ตัว, ชนะบอส 1 ตัว — ทำเสร็จแล้ว **เลือกรางวัลเองได้** (ทอง / XP / ไอเทมสุ่ม) และทำครบทุกภารกิจได้โบนัสพิเศษ (ทอง + XP + ไอเทม)
- **streak ภารกิจ** — ทำครบติดต่อกันหลายวัน โบนัสเพิ่ม 20%/วัน สูงสุด x2
- ✨ **ไอเทมพิเศษ (✦ พิเศษ)** — ของ Exclusive 5 อย่างที่หาซื้อตามร้านไม่ได้ (ถุงเงินนำโชค, คัมภีร์ประสบการณ์, สมุดนำโชค, มงกุฎนักโฟกัส, อีลิกเซอร์บริสุทธิ์) ได้จากการเลือกรางวัล "ไอเทมสุ่ม" (40%) หรือโบนัสครบทุกภารกิจ (35%) เท่านั้น

### 🏅 ระบบ Achievement (54 ตรา: ปกติ 34 + ลับ 20)

- ปลดล็อกอัตโนมัติเมื่อถึงเงื่อนไข ได้รางวัลทอง/XP ดูความคืบหน้าได้ที่แท็บ "ตรา"
- รวมตราใหม่ **🎭 เต็มยศประจำคลาส** (สวมอุปกรณ์เฉพาะคลาส 2 ชิ้น), สายค้าตลาดมืด: **🖤 สายค้าตลาดมืด** (ซื้อจากตลาดมืด 3 ครั้ง) / **👑 ราชาตลาดมืด** (10 ครั้ง), **โหมดท้าทาย**: ⚔️ นักสู้สุดหิน / ⏱️ จิตใจเหนือเหล็ก / 🩸 เอาชีวิตรอด (จบ 1 รอบเมืองในโหมดนั้น), และ **ระบบต่อสู้บอส**: 🛡️ จอมสลาย / 💥 ราชันย์จอมสลาย (สลายท่าไม้ตาย 5 / 15 ครั้ง), ⚡ สยบจอมชาร์จ (ชนะโดยสลายท่าไม้ตายในไฟต์นั้น), 🔥 อดทนที่สุด (ชนะตอนบอสสุดทน), และ **ของแถม**: 🎁 นักเก็บของแถม / 🎁 ราชาแห่งของแถม (เก็บของแถม — ซื้อของราคา 0 — 5 / 15 ชิ้น)
- **ตราปกติ** — session, บอส, มอนสเตอร์, สมบัติ, ภารกิจ, คอมโบ, เลเวล, ทอง, สลายท่าไม้ตาย ฯลฯ (โชว์ความคืบหน้า)
- **ตราลับ** — เงื่อนไขซ่อนไว้ (โชว์เป็น "???" พร้อมคำใบ้ลึกลับ เช่น โฟกัสตอนตี 2, ชนะบอสตอน HP=1, สู้บอสโดยไม่สวมอุปกรณ์, พิชิตครบ 12 เมือง) รางวัลสูงกว่า

### 🗺️ การเดินทาง

- **12 เมือง** (หมู่บ้านอีสตาร์ → แอสการ์ด → หุบเขามรกต/นครสายฟ้า/ทะเลทรายนิรันดร์/อาณาจักรมังกร) — ชนะบอสทีละเมืองเพื่อเดินทางต่อไป (บอสและมอนสเตอร์แข็งแกร่งขึ้นตามเลเวล)
- **เดินทางย้อนกลับ** ไปเมืองที่เคยไปมาแล้วได้ (เสีย 20 ทอง/เมือง — ไปข้างหน้าต้องชนะบอสเท่านั้น)
- 🏠 **สำรวจเมืองเดิมต่อ** — หลังชนะบอส เลือกได้ว่า "เดินทางต่อ" (เมืองใหม่) หรือ "สำรวจเมืองเดิมต่อ": ศัตรู/บอสแข็งขึ้น **x1.15/รอบ** แต่รางวัล XP/ทอง **x1.2/รอบ** + โอกาสเจอตลาดมืดเพิ่ม (+10%/รอบ สูงสุด +35%) — ครบรอบที่เมืองนั้น (แต่ละเมืองไม่เท่ากัน: 2/3/4 รอบสลับกัน) จะเจอ **บอสลับ** (👁️/😈/🗿 — แข็งขึ้นอีก x1.15) ที่ให้ของพิเศษขายแพง (ได้ครั้งเดียวต่อเมือง — มีแล้วได้ค่าหัวทองแทน) — หนีบอส (แพ้) กลับไปสำรวจใหม่แบบไม่นับรอบ ไม่เพิ่มความยาก · **รอบปัจจุบันโชว์ที่หน้า Home (ป้าย 🏠 รอบ X) + หน้าจอโฟกัส** พร้อม tooltip บอกตัวคูณ

### ⚡ ระบบสนับสนุนการโฟกัส

- 🔥 **คอมโบโฟกัส** — ทำ session ต่อเนื่องไม่ทิ้ง ได้โบนัส XP สูงสุด x1.5 · 🛡️ **โล่โฟกัส** — กันคอมโบหาย 1 ครั้งเมื่อพัก/ทิ้ง session (สถานะโล่โชว์ทั้งบนหน้าหลัก + หน้าจอโฟกัส)
- 📋 **ชื่องาน** — ตั้งก่อนเริ่มโฟกัสได้ เก็บข้าม session ในรอบเดียวกัน (รีโหลดหน้าก็ไม่หาย) และแก้ไขกลางทางได้จากปุ่ม ✏️ บนหน้าจอโฟกัส
- 🆕 **วิธีเล่นสำหรับคนใหม่** — เด้ง modal สรุปการเล่น 5 ขั้นตอนเฉพาะตอนเริ่มเกมใหม่จริง ๆ (สร้างตัวแรกจากลิสต์ว่าง / หลังล้างข้อมูล) ปิดแล้วไม่โผล่อีก
- 📱 **PWA** — ติดตั้งเป็นแอพบนมือถือได้ (Add to Home Screen) ใช้งานแบบ standalone
- 🔔 **แจ้งเตือนเบราว์เซอร์** — เด้ง notification ของระบบตอนจบ session / พักหมด / ถึงเวลาสู้บอส (ขออนุญาตครั้งแรกตอนเริ่มโฟกัส — แจ้งเฉพาะตอนแท็บอยู่เบื้องหลัง, เปิด/ปิดได้ในแท็บตั้งค่า)

### 📊 หน้า Stats

- **สรุปรายสัปดาห์** — session/เวลา/XP/ทอง/บอส/มอนสเตอร์/เมือง/ตรา เทียบสัปดาห์ก่อน พร้อม ↑↓%
- กราฟโฟกัสย้อนหลัง 7 วัน + กราฟจำนวน session ต่อวัน (7 วัน + 30 วัน — **สลับดูเป็นเวลาโฟกัสได้**) + heatmap 12 สัปดาห์
- **กราฟเวลาพัก 7 วัน** — แท่งสาม: พักเบรกระหว่าง session + **พักกลาง session (⏸️ พักสั้น)** + **พักยาว 😴 (นอน/ธุระ)** พร้อม legend
- **😴 พักยาวแยกตามชื่อ (30 วัน)** — เวลารวม + จำนวนครั้งต่อชื่อพัก (จากตัวเลือกสำเร็จรูป — ดูว่าเวลาไปกับอะไรบ้าง)
- เวลาโฟกัสสะสม + สถิติต่อสู้ + **🖤 สถิติตลาดมืด** (ซื้อ/ขาย/ทองที่ใช้/ทองที่ได้/กำไรสุทธิ) + สถิติแยกตามงาน + เส้นทางการเดินทางข้ามเมือง

### 👹 ระบบต่อสู้บอส

สู้บอสแบบเทิร์น-by-เทิร์น (กดโจมตี/สกิล/ใช้ยาเอง ไม่รบกวนสมาธิเพราะเป็นช่วงพักยาว) — ออกแบบให้ต้อง **เลือกกลยุทธ์** ไม่ใช่แค่กดโจมตีซ้ำ ๆ:

| กลไก | รายละเอียด |
|---|---|
| 🛡️ **ตั้งรับ** | ปุ่มใหม่ (ไม่มีค่าใช้จ่าย) — ลดดาเมจที่ได้รับ **60% ในเทิร์นนั้น** + ฟื้น MP 10% ใช้รับมือท่าไม้ตายหรือรอฟื้นมานา |
| 😡 **โกรธจัด (เฟส 2)** | เมื่อ HP บอส ≤ 50%: ATK พุ่ง **x1.4** + ใช้ท่าเด็ดถี่ขึ้น (30%→45%) + ได้ท่าไม้ตาย 💥 (x2.2, โอกาส 25%) + **ต้านทานแช่แข็ง** (โอกาสลดลงครึ่ง) — ป้ายแดงกะพริบบนการ์ดบอส |
| ⚠️ **ชาร์จท่าไม้ตาย** | ทุก 5 เทิร์น บอสหยุดชาร์จพลัง (เตือนไว้ใน log + บนการ์ด พร้อมชื่อท่าที่กำลังจะปล่อย) — ถ้าผู้เล่นทำดาเมจได้ **≥ 12% ของ HP สูงสุดบอส** ในเทิร์นที่ชาร์จ → **สลายได้!** บอสชะงัก (ข้ามเทิร์น) · สลายไม่ได้ → ตั้งรับ 🛡️ ลดดาเมจ หรือโดนเต็ม ๆ |
| 🎭 **ท่าไม้ตายเฉพาะตัว** | แต่ละบอสมีท่าไม้ตายสไตล์ต่างกัน (โชว์บนการ์ด): 💥 **ท่าไม้ตาย** — โจมตีมหึมา x2.6 · 🛡️ **เกราะมหึมา** — บอสติดเกราะลดดาเมจ 60% (2 เทิร์น) · 💚 **พลังฟื้นฟู** — บอสฟื้น HP 40% ทันที · 💨 **เงามายา** — บอสหลบโจมตีคุณ 50% (2 เทิร์น, พิษโดนแน่นอน) — รู้จักศัตรูให้ดีก่อนตัดสินใจสลาย! |
| 🔥 **สุดทน** | สู้ยืดเยื้อเกิน 30 เทิร์น → ATK บอสพุ่ง **x1.6 ถาวร** (กันกักยาไว้เฉย ๆ) |
| 🗺️ **สเกลตามเมือง** | บอสยิ่งเมืองลึก ยิ่งแข็ง **(x1.05/เมือง)** — เมือง 12 โหดกว่าเมืองแรก ~x1.55 (ซ้อนกับ x1.15/รอบของการสำรวจเมืองเดิมต่อได้อีก) |
| ✨ **รางวัลฝีมือ** | สลายท่าไม้ตาย = **+8% XP/ทอง ต่อครั้ง** (สูงสุด +24%) · ชนะตอนบอสสุดทน = **+15% ทอง** · ชนะโดยสลาย ≥1 ครั้ง **หรือ** ตอนสุดทน → **ของรางวัลบอสการันตี** (แทนสุ่ม 50%) — โชว์โบนัสใน log + หน้าจอชนะ |
| 🐉 **บอสเร่ร่อน (รายสัปดาห์)** | สุ่มมาแทนบอสปกติของเมืองในบางสัปดาห์ (deterministic จากสัปดาห์+ตัวละคร+เมือง — ป้าย 🐉 บนการ์ด) — ชนะได้ **ของรางวัลการันตี + แบบแปลนสูตรคราฟต์ 📋** (แหล่งหาแบบแปลนที่แน่นอน) |
| 🏆 **ห้องเก็บถ้วยรางวัล** | ชนะบอสแต่ละตัวเป็นครั้งแรก (เมือง/บอสลับ/บอสเร่ร่อน) → เก็บถ้วยในแท็บใหม่ของค่ายพัก — เป้าหมายสะสมระยะยาว (ซ้ำไม่เพิ่ม) |

บอสยังมีสกิลประจำเมือง (คลั่ง/ทุบแหลก/เรียกพลัง/พิษร้าย/เกราะแข็ง/ดูดมานา) เหมือนเดิม และระบบหลบ (SPD) คริติคอล พิษ/แช่แข็ง/โล่เวท ทำงานร่วมกับกลไกใหม่ — การ์ดบอสโชว์สถานะ (😡/🔥/⚠️/🛡️ เกราะ/💨 หลบ) ให้วางแผนได้ทันที

### 📜 บันทึก & ประวัติ

- **บันทึกการผจญภัย** — ดูประวัติทุกเหตุการณ์ รางวัล (รวมพลังที่เสีย/ฟื้นจากเหตุการณ์) และสถิติสะสม — ทุก session จะมีรายการสรุปกำกับ label เช่น `📋 Session 2/4 @ 21:09` (สรุปชนิดเหตุการณ์ + ของรางวัลรวม) เก็บ 1 แถวต่อ session
- **ประวัติ Session** (แท็บ Session) — ดู session ย้อนหลังเรียงล่าสุดก่อน **กรองได้ 3 แบบ: วันที่ / เมือง (dropdown เฉพาะเมืองที่เคยผ่าน) / คำค้น** กดขยายดูเหตุการณ์ทั้งหมดใน session นั้นได้ + **badge โหมดท้าทายตอนนั้น** (⚔️/⏱️/🩸 — ถึงเปลี่ยนโหมดไปแล้วก็ยังเห็นว่า session นั้นเล่นโหมดอะไร)

## ➕ เพิ่มเนื้อหาเกมเอง (มอนสเตอร์ / อุปกรณ์ / เมือง)

ข้อมูลเกมทั้งหมดอยู่ในไฟล์เดียว: **`server/data.js`** — เกม engine อ่านจาก array เหล่านี้โดยตรง ดังนั้น **เพิ่มเนื้อหาใหม่ไม่ต้องแตะโค้ดอื่นเลย** (ไม่ต้องแก้ engine, API หรือ UI) เปิดแอพใหม่แล้วใช้งานได้ทันที

### 🐾 เพิ่มมอนสเตอร์

เพิ่ม entry ใน `MONSTERS` array:

```js
{ name: 'กอร์กอน', icon: '🐍', power: 1.4, xp: 48, gold: 30, loot: 120 },
```

| field | ความหมาย |
|---|---|
| `name` / `icon` | ชื่อและอีโมจิแสดงผล |
| `power` | ตัวคูณพลังตามเลเวลตัวละคร (0.7 = อ่อน, 1.5 = แรง) — ยิ่งสูงยิ่งชนะยาก |
| `loot` | **(ไม่บังคับ)** id ของไอเทมขยะประจำตัวมอนสเตอร์ (ดูใน `ITEMS`) — **ชนะมอนสเตอร์มีโอกาส ~40%** ได้ของนี้ (ขยะราคาต่ำ ขายได้ที่แคมป์) — ถ้าไม่ระบุ ไม่มี loot |
| `xp` / `gold` | รางวัลพื้นฐานตอนชนะ (ได้เพิ่มตามเลเวลอัตโนมัติ) |

### ⚔️ เพิ่มอุปกรณ์ / ไอเทม

เพิ่ม entry ใน `ITEMS` array — ช่องสวมใส่ถูกเลือกอัตโนมัติจาก `type` (11 ช่อง: มือหลัก/มือรอง/หมวก/เกราะ/แขน/ขา/เท้า/เครื่องประดับ x4):

```js
// อาวุธ (handed: 1 = มือเดียว → ใส่มือหลักหรือมือรอง, 2 = สองมือ → มือหลัก + ปิดมือรอง)
{ id: 14, name: 'ดาบเพลิง', icon: '🔥', type: 'weapon', atk_bonus: 12, price: 260, desc: 'ดาบที่ร้อนแรง', lvl: 4, handed: 1 },

// เกราะ/หมวก/แขน/ขา/เท้า/โล่/เครื่องประดับ (ใส่ช่องตาม type)
{ id: 50, name: 'โล่ไม้', icon: '🛡️', type: 'shield', def_bonus: 4, hp_bonus: 8, price: 45, desc: 'โล่ไม้เก่า ๆ', lvl: 1 },

// ของใช้ (กิน/ใช้แล้วหาย) — heal_pct / mana_pct / use_gold / use_xp
{ id: 45, name: 'ยามหัศจรรย์', icon: '🍯', type: 'consumable', heal_pct: 0.5, mana_pct: 0.3, price: 90, desc: 'ฟื้น HP 50% และ MP 30%' },
```

| field | ความหมาย |
|---|---|
| `id` | **ต้องไม่ซ้ำกัน** (ระบบใช้ id เป็น key) — ตอนนี้ใช้ 1-4 ยา, 5-7 สมุนไพร, 10-17 อาวุธ, 20-23 เกราะตัว, 30-37 เครื่องประดับ, 40-44 exclusive, 45-49 junk, 50-52 โล่, 60-62 หมวก, 70-72 แขน, 80-82 ขา, 90-92 เท้า, **200-207 ไอเทมเฉพาะคลาส** (ขวานมังกรเพลิง/เกราะไททัน=นักรบ, คทาแสงจันทร์/เสื้อคลุมเวทมนตร์=นักเวทย์, มีดอาบพิษ/ชุดเงา=โจร, ค้อนศักดิ์สิทธิ์/ชุดนักบวช=นักบวช) |
| `type` | `weapon` / `shield` / `armor` (ตัว) / `head` (หมวก) / `arms` / `legs` / `feet` / `accessory` (เครื่องประดับ) หรือ `consumable` (ของใช้) |
| `handed` | **(เฉพาะ weapon)** `1` = มือเดียว (มือรองใส่ได้), `2` = สองมือ (มือรองถูกปิดอัตโนมัติ) |
| โบนัส | ตามประเภท: `atk_bonus` `def_bonus` `hp_bonus` `mp_bonus` `spd_bonus` `crit_bonus` (อุปกรณ์), `heal_pct` `mana_pct` `use_gold` `use_xp` (ของใช้) |
| `lvl` | ระดับขั้นต่ำที่สวม/ดรอปได้ (อุปกรณ์) — ดรอปต้อง `lvl ≤ เลเวลตัวละคร + 1` |
| `classReq` | **(ไม่บังคับ)** array ของคลาสที่สวมได้ เช่น `['warrior']` `['mage','cleric']` — คลาสอื่นสวมไม่ได้ (ร้านค้า/ดรอป/รางวัล Daily จะกรองของคลาสอื่นออกให้อัตโนมัติ) |
| `statReq` | **(ไม่บังคับ)** ค่าสถานะขั้นต่ำ (รวมอุปกรณ์ที่สวมอยู่) เช่น `{ atk: 20 }` `{ def: 12, spd: 16 }` — ไม่ถึงเกณฑ์สวมไม่ได้ (คีย์: `atk` `def` `spd` `mp` `crit`) — ชิปบนไอเทมแสดงระยะห่างด้วย (เช่น "ATK 20+ (ขาด 6)" เทียบกับค่าปัจจุบัน) และไอเทมในร้านค้าจะมีป้ายเตือน ⚠️ "ซื้อแล้วสวมไม่ได้ตอนนี้" ถ้ายังไม่ถึงเกณฑ์ |
| `price` / `desc` | ราคาขายในร้านและคำอธิบาย |
| `exclusive: true` | **(ไม่บังคับ)** ตั้งไว้ = ไอเทมพิเศษเฉพาะ Daily Quest — **ร้านค้าไม่ขาย** และไม่ดรอปตามปกติ (ได้จากการเลือกรางวัล "ไอเทมสุ่ม" / โบนัสครบภารกิจเท่านั้น) |

### ⚠️ ข้อควรรู้

- **ร้านค้า:** ขายอุปกรณ์ทุกชิ้นที่ `ไม่ใช่ exclusive` อัตโนมัติ แต่ **ของใช้ (consumable) ขายเฉพาะ id 1-4** — ถ้าอยากขายยาตัวใหม่ในร้าน ต้องเพิ่ม id ในเงื่อนไข `SHOP_STOCK` (บรรทัดเดียวกับนิยาม `SHOP_STOCK` ใน `data.js`)
- **การดรอป:** เกมสุ่มดรอปตามระดับ — อุปกรณ์ `lvl` สูงเกินเลเวลตัวละครจะยังไม่ดรอป (ตั้งใจให้เป็นของหายาก)
- **exclusive:** ไอเทม `exclusive: true` จะถูกกรองออกจากร้านและดรอปทั้งหมดอัตโนมัติ — ใช้สำหรับของ Daily Quest เท่านั้น
- **เมือง & บอส:** เพิ่มได้เหมือนกัน (เพิ่ม `CITIES` + `BOSSES` คู่กัน จำนวนต้องเท่ากัน เพราะบอสผูก index กับเมือง) — บอสรับ field `loot` (id ไอเทมขยะ) ชนะแล้วดรอป ~50% — แต่ระวังตราลับ "ผู้พิชิตแอสการ์ด" ที่ผูกกับ index เมืองที่ 8 (แก้ใน `data.js` → `SECRET_ACHIEVEMENTS` ได้)

## 🤖 ระบบ LLM (เนื้อเรื่องสุ่มเสริม)

เกมสามารถเชื่อม **LLM** เพื่อเขียน "เรื่องราวการผจญภัย" สั้น ๆ ลงในบันทึกหลังจบแต่ละ session (📖 เรื่องราวการผจญภัย) — เนื้อเรื่องไม่ซ้ำเดิมทุกครั้ง ภาษาไทยปนอังกฤษตามสไตล์เกม

> ⚠️ LLM เขียนแค่ **ข้อความบรรยายเท่านั้น** — XP/ทอง/ไอเทม/รางวัลทั้งหมดยังคำนวณที่ server ตามเดิม (กันโกง + กัน balance พัง) และ **ถ้าไม่มี key หรือ API error เกมจะใช้ข้อความตายตัวเดิมปกติ** ไม่พัง

### วิธีเปิดใช้ — ค่า default ชี้ไป LLM ในเครื่อง (`localhost:8080/v1`)

**รันตามปกติได้เลย ไม่ต้องตั้ง env อะไร** — โมดูลจะเรียก `http://localhost:8080/v1/chat/completions` ด้วย `model: "default"` โดยอัตโนมัติ (กรณี base URL เป็น localhost เกมจะเปิดใช้ LLM เอง ไม่ต้อง auth):

```bash
npm run dev
```

> ตัวอย่าง: รัน g4f instance / Ollama / LLM server ใดก็ได้ที่ OpenAI-compatible ไว้ที่ port 8080 (เช่น `g4f` local: `python -m g4f`)

ตั้งค่าเพิ่มเติม (ไม่บังคับ):

```bash
LLM_BASE_URL=http://localhost:8080/v1   # base URL ของ API (ค่า default)
LLM_MODEL=default            # ชื่อโมเดล — ค่า default คือ "default"
LLM_TIMEOUT_MS=30000         # timeout ต่อ request (เผื่อ cold start โมเดล local)
LLM_ENABLED=0                # บังคับปิด LLM (ไม่เรียกเลย)
```

### ใช้กับ g4f.space (remote — ต้อง auth)

- **g4f.space ตรวจ credits ฝั่ง backend** — ต่อให้ใช้ `g4f.dev/dist/js/client.js` ใน browser ตรง ๆ ก็เจอ error `402 No cake credits` ถ้าเครื่องยังไม่มี credits (ทดสอบจริงแล้ว)
- วิธีใช้: bake proof-of-work ฟรีที่ `g4f.dev/chat` → credits ผูกกับ IP → รันด้วย `LLM_ENABLED=1 npm run dev` (ไม่ต้อง key) หรือสมัคร `g4f.dev/members.html` เอา key มาใส่ `LLM_API_KEY`

```bash
LLM_ENABLED=1 npm run dev          # credits ผูก IP (bake ฟรีแล้ว)
LLM_API_KEY=xxxx npm run dev       # มี key
```

### จุดที่ LLM ถูกใช้ตอนนี้

| จุด | ผลลัพธ์ |
|---|---|
| หลังจบ work session (`/adventure/complete`) | เขียนเรื่องราว 2-3 ประโยคจากบริบท (ตัวละคร/เมือง/เวลาที่โฟกัส/คอมโบ) → บันทึกเป็น log "📖 เรื่องราวการผจญภัย" |

## 🧪 Dev Test Panel

เข้าได้จากหน้าแรก (ปุ่ม dev) — **เข้าสู่ระบบด้วย `admin/admin`** (ตั้งค่าเองได้ผ่าน env `DEV_USER` / `DEV_PASS`) มีปุ่มทางลัดเข้าสู่ระบบแบบคลิกเดียว

ทดสอบได้ทั้ง: สุ่มเหตุการณ์ระหว่าง session (บังคับ event ตามชนิดได้), จบ session / พักเบรก, ภารกิจสุ่ม, ซื้อของ, ชนะบอสทันที, เติม HP/MP เต็ม, ย้ายเมืองถัดไป, เรื่องราวทดสอบ, เรียนรู้สกิล / +XP สกิล, ให้ไอเทม / ทอง / XP, ปลดล็อกตรา, และ **ดูตัวอย่างตลาดมืด** (🖤 — โชว์รายการ 4 ชิ้น + ราคาลด + อัตรารับซื้อขยะ เป็น preview ล้วน ไม่มีผลกับเกมจริง) — token อยู่ในหน่วยความจำ server (รีสตาร์ทแล้วต้อง login ใหม่)

> ⚠️ **ปุ่ม /dev/* เป็นโหมดลองเล่น** — รัน action ใน transaction แล้ว **ROLLBACK ทันที**: แสดงผลเหมือนจริง (เลเวล/ทอง/ไอเทม/ตราที่ได้) แต่ **ไม่บันทึกลง DB** (กันปั๊มเลเวล) · เฉพาะปุ่มที่เรียกระบบจริงของเกม (event/session/ภารกิจ/ซื้อ) ยังบันทึกตามปกติ
